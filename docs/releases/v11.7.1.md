# NOOP v11.7.1

WHOOP strap-memory history is now the single durable authority for WHOOP R-R intervals.

The standard Bluetooth 2A37 path and WHOOP R10/R11 realtime path continue to be subscribed, decoded
and delivered to live consumers. Their R-R intervals stop at the persistence boundary and never enter
the canonical `rrInterval` dataset. Live heart rate keeps its existing persistence behaviour.

Historical/offload R-R continues through the existing database model without averaging, fuzzy matching,
timestamp deduplication or one-interval-per-second collapsing. Existing rows are not cleaned or rewritten,
and this release adds no schema or migration.

Each historical offload reports fresh-data coverage before storage: interval count, occupied seconds,
summed R-R duration, represented span, duration/span ratio, delivery histogram and gap histogram. This
makes post-11.7.1 coverage measurable without legacy multi-source rows contaminating the result.

No HRV, sleep, respiratory-rate, strain or recovery algorithm changes in this release.
